Windows 11 Troubleshooting Lab
Overview

A hands-on IT support learning project documenting Windows 11 system diagnostics, hardware identification, performance monitoring, and troubleshooting procedures.

Objectives
- Practice Windows 11 diagnostic tools.
- Investigate system performance and hardware information.
- Analyze Windows event logs.
- Document troubleshooting procedures and findings.
- Develop practical skills relevant to entry-level IT support.
Tools
- Windows 11
- System Information (msinfo32)
- Task Manager
- Device Manager
- Event Viewer
- Disk Management
Project Status: In Progress
